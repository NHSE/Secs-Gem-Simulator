# 🛠 SML FORMAT

본 문서는 **SECS/GEM 메시지 전송에 사용되는 SML 파일 형식**을 설명합니다.

SML파일은 장비와 호스트 간 HSMS/SECS-II 메시지를 정의하는 텍스트 기반 형식입니다.

예시 파일은 [예시파일](/example/example.sml) 를 참조하세요.

SML 파일은 **상기 이미지와 동일한 형식**을 따라야 합니다.  
형식이 올바르지 않을 경우 다음과 같은 문제가 발생할 수 있습니다.

- 파일 파싱 오류
- SECS/GEM 메시지 전송 실패
- 메시지 데이터 손상

---

### 📌 SML 작성 규칙

- `A` 타입을 **제외한 모든 타입**은 반드시 **`[length]`** 를 명시해야 합니다.
- 명시된 **`[length]`** 가 실제 길이와 다를 경우 오류가 발생합니다.
- 각 SML 메시지는 반드시 **`>.`** 로 종료되어야 합니다.
- 종료 문자가 누락될 경우 메시지의 끝을 인식할 수 없어 오류가 발생합니다.

```text
예시:
S1F1 W
<L [2]
  <A "TEST">
  <U4 [1] 10>
>.
```

### ⚠️ 주의 사항

SML 문법 오류가 있는 파일은
File 파싱 단계에서 즉시 오류 처리됩니다.

전송 가능한 메시지는
정상적으로 파싱된 SML 데이터만 리스트업됩니다.
